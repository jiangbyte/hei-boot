# IAM 字典待补

Admin IAM 页面使用字典工具，不写本地枚举。下列编码在字典管理中补齐后页面即生效。

| 字典编码 | 用途 | 建议值 | 状态 |
|----------|------|--------|------|
| `ACCOUNT_TYPE` | 账号类型 | `ADMIN`、`PORTAL` | V2 seed 已有 |
| `ACCOUNT_STATUS` | 账号状态 | `ENABLED`、`DISABLED`、`CANCELLED` | 待补 |
| `COMMON_STATUS` | 通用状态 | `ENABLED`、`DISABLED` | 待补 |
| `DEPT_CATEGORY` | 部门分类 | 按业务补充 | 待补 |
| `POSITION_CATEGORY` | 岗位分类 | 按业务补充 | 待补 |
| `ROLE_CATEGORY` | 角色分类 | 按业务补充 | 待补 |
| `ROLE_SCOPE_TYPE` | 角色数据范围 | `PLATFORM`、`DEPT` | 待补 |
| `RESOURCE_TYPE` | 资源类型 | `CATALOG`、`MENU`、`PAGE`、`BUTTON`、`ACTION`、`API_GROUP` | 待补 |

颜色建议使用十六进制色值。
